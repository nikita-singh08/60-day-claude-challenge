# Day 39 – PDF Splitter & Merger

## Objective

Build and test an interactive **PDF Splitter & Merger** application using Claude AI to split, merge, preview, and download PDF files directly in the browser.

## Task Performed

Today I used Claude AI to generate an interactive HTML application called **PDF Splitter & Merger**.

The workflow included:

1. Reading the provided resources.
2. Watching the solution video.
3. Opening Claude.
4. Setting the Claude effort level to Low.
5. Starting a new conversation.
6. Using the provided PDF Splitter & Merger prompt.
7. Answering Claude's interview question.
8. Generating the complete HTML application.
9. Saving the generated HTML file.
10. Opening the application locally in a web browser.
11. Testing the PDF Splitter.
12. Testing the PDF Merger.
13. Previewing and downloading processed PDFs.
14. Taking screenshots of the application and results.

## Key Learnings

- AI can be used to build useful browser-based document-processing tools.
- PDF splitting allows large documents to be divided into smaller files.
- PDF merging is useful for combining multiple documents into a single PDF.
- Client-side web applications can provide convenient file-processing workflows.
- Preview and download features make document tools more practical for users.
- Handling uploaded files requires careful validation and user-friendly feedback.

## My Reflection

This task helped me understand how AI can be used to create practical document-processing applications. The PDF Splitter & Merger demonstrated how browser-based tools can simplify common PDF tasks without requiring a complex user interface.

I also learned how multiple file-processing features can be combined into a single application to create a more useful and complete productivity tool.
