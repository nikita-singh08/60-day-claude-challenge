# Day 33 – Media Integrity Analyzer

## Objective

Build and test an AI-powered Media Integrity Analyzer that helps identify misleading headlines, detect emotional manipulation, and evaluate the integrity of media content through interactive challenges and a live dashboard.

## Task Performed

Today I used Claude AI to generate an interactive HTML application called **Media Integrity Analyzer**.

The workflow included:

1. Starting a new conversation in Claude.
2. Using the provided Media Integrity Analyzer prompt.
3. Generating the complete HTML application.
4. Saving the generated HTML file.
5. Opening the application in a web browser.
6. Choosing a preferred color theme.
7. Completing the Headline Detective challenge.
8. Reviewing the headline analysis and rewritten headline.
9. Completing the Emotion Detector challenge.
10. Analyzing the emotional manipulation techniques.
11. Observing how the live Media Integrity metrics updated.
12. Reviewing the final Media Integrity Dashboard.
13. Replaying the analyzer using new randomized scenarios.
14. Taking screenshots of the results.

## Key Learnings

- Headlines can influence how readers interpret information before they read the full story.
- Emotional language can be used to influence audience reactions.
- Identifying manipulation techniques helps improve critical evaluation of media content.
- Rewriting sensational headlines into more neutral language can improve clarity and objectivity.
- Interactive scoring and dashboards can make media-literacy concepts easier to understand.
- Testing randomized scenarios helps apply the same evaluation principles to different examples.

## My Reflection

This task helped me understand how AI can be used as an educational tool for evaluating media content. The analyzer demonstrated how headline framing, emotional language, and other communication techniques can influence the perception of information.

The interactive challenges also showed how structured analysis can help develop stronger critical-thinking and media-literacy skills.
