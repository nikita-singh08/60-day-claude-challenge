# Day 20 – AI Face Puzzle Game

## Objective

Learn how to use AI to generate an interactive Face Puzzle Game using HTML, CSS, and JavaScript. The application captures a photo using the webcam, converts it into a sliding puzzle, and allows users to solve it while tracking time, moves, and leaderboard scores.

---

# Task Performed

Today I used Claude to generate a complete Face Puzzle Game application.

The workflow included:

1. Starting a new conversation in Claude.
2. Setting Claude's effort level.
3. Using the provided Face Puzzle Game prompt.
4. Generating the complete HTML application.
5. Saving the generated HTML file.
6. Opening the application in a web browser.
7. Granting webcam permissions.
8. Capturing a photo using the camera.
9. Selecting a puzzle difficulty (3×3, 4×4, or 5×5).
10. Playing the puzzle game.
11. Testing drag-and-drop and touch interactions.
12. Verifying the timer, move counter, and leaderboard.
13. Completing the puzzle and reviewing the final results.
14. Capturing screenshots of the application and gameplay.

# Application Features

The generated Face Puzzle Game included:

- Webcam photo capture
- Sliding puzzle gameplay
- Difficulty selection (3×3, 4×4, 5×5)
- Drag-and-drop support
- Touch support for mobile devices
- Timer
- Move Counter
- Leaderboard
- Responsive UI
- Interactive animations

---

# Testing

The application was tested by:

- Capturing a live image using the webcam.
- Generating puzzles at different difficulty levels.
- Verifying drag-and-drop functionality.
- Testing touch interactions.
- Completing the puzzle.
- Checking timer and move tracking.
- Verifying leaderboard functionality.

---

# Key Learnings

- AI can generate complete interactive web applications.
- Browser APIs such as the Webcam API can be integrated using AI-generated code.
- HTML, CSS, and JavaScript are sufficient for creating engaging browser games.
- AI significantly reduces development time for frontend projects.
- Testing is essential to ensure all interactive features work correctly.

# My Reflection

Today's activity demonstrated how AI can generate a complete browser-based game with modern UI and interactive functionality. Combining webcam access, puzzle logic, and responsive design highlighted the ability of AI to rapidly build creative web applications from a single prompt.
