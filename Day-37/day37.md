# Day 37 – Task Compass

## Objective

Build and test an interactive Task Compass application that helps explore task ownership, task routing, collaboration, and organizational thinking through workplace-based challenges.

## Task Performed

Today I used Claude AI to generate an interactive HTML application called **Task Compass**.

The workflow included:

1. Opening Claude and setting the effort level to Low.
2. Starting a new conversation.
3. Using the provided Task Compass prompt.
4. Choosing a workplace type.
5. Generating the complete HTML application.
6. Saving the generated HTML file.
7. Opening the application locally in a web browser.
8. Completing Stage 1: Who Owns This?
9. Completing Stage 2: Task Routing.
10. Completing Stage 3: Collaboration Challenge.
11. Reviewing the Organizational Thinking Dashboard.
12. Replaying the application using another workplace type.
13. Taking screenshots of the results.

## Tools Used

- Claude AI
- HTML
- CSS
- JavaScript
- Web Browser

## Features Tested

- Workplace Type Selection
- Who Owns This? Challenge
- Task Routing
- Collaboration Challenge
- Organizational Thinking Dashboard
- Workplace Scenario Analysis
- Replay with Different Workplace Types

## Key Learnings

- Clearly identifying task ownership helps prevent confusion and duplicated work.
- Proper task routing can improve coordination and organizational efficiency.
- Collaboration requires understanding responsibilities and communication between different roles.
- Different workplace environments can require different approaches to task management.
- Interactive scenarios can make organizational and collaboration concepts easier to understand.
- Reviewing the Organizational Thinking Dashboard helps identify patterns in decision-making and task management.

## My Reflection

This task helped me understand how task ownership, routing, and collaboration affect the way work is organized.

The different stages provided practical situations where I had to think about who should handle a task, how it should be routed, and how different people or teams should collaborate.

Replaying the experience with another workplace type also showed how organizational decisions can vary depending on the work environment.
