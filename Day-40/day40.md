# Day 40 – AI Assistant Builder

## Objective

Build and test an AI Assistant Builder using Claude AI to understand how custom AI assistants can be created, configured, and tested with system prompts and documentation.

## Task Performed

Today I used Claude AI to generate and test an interactive HTML application called **AI Assistant Builder**.

The workflow included:

1. Reading the provided resources.
2. Watching the solution video.
3. Opening Claude.
4. Setting the Claude effort level to Low.
5. Starting a new conversation.
6. Using the provided AI Assistant Builder prompt.
7. Answering Claude's interview questions using the MCQ quiz format.
8. Generating the complete HTML application.
9. Publishing the Claude artifact for testing.
10. Testing the generated AI assistant.
11. Reviewing the generated system prompt.
12. Exploring the documentation panel.
13. Taking screenshots of the assistant, system prompt, and documentation.

## Key Learnings

- AI assistants can be configured using detailed system prompts that define their behavior and responsibilities.
- Structured questions can help collect the information required to build a useful AI assistant.
- System prompts play an important role in controlling how an AI assistant responds.
- Testing an assistant with different inputs helps identify whether it follows its intended instructions.
- Documentation panels can make AI tools easier to understand and use.
- Claude artifacts provide a convenient way to create and test interactive AI-powered applications.
- When running an HTML application outside Claude, live API-based functionality may require an appropriate Anthropic API key.

## My Reflection

This task helped me understand the basic process of designing a custom AI assistant. I learned that building an AI assistant is not only about generating responses but also about defining its role, behavior, instructions, and expected outputs.

The system prompt was especially useful for understanding how an assistant's behavior can be structured and controlled. Testing the assistant also showed me the importance of validating whether the generated assistant actually follows its intended instructions.
