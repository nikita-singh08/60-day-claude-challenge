# Day 35 – Prompt Puzzle

## Objective

Build and test an interactive Prompt Puzzle application that helps practice prompt engineering through multiple challenges, different domains, and performance evaluation.

## Task Performed

Today I used Claude AI to generate an interactive HTML application called **Prompt Puzzle**.

The workflow included:

1. Reading the provided resources.
2. Watching the solution video.
3. Opening Claude and setting the effort level to Low.
4. Using the provided Prompt Puzzle prompt.
5. Answering the two onboarding questions.
6. Generating the complete HTML application.
7. Saving the generated HTML file.
8. Opening the application locally in a web browser.
9. Playing through all three prompt challenges.
10. Reviewing the Prompt Performance Report.
11. Replaying the puzzle using another domain or difficulty.
12. Taking screenshots of the application and results.

## Key Learnings

- Clear and specific prompts help AI understand the intended task more effectively.
- Providing relevant context can improve the quality and usefulness of AI responses.
- Different domains may require different prompting approaches.
- Prompt structure and instructions can influence the quality of generated results.
- Testing prompts through multiple challenges helps identify weaknesses and improve prompt quality.
- Performance reports can provide useful feedback about how effectively a prompt performs.
- Replaying challenges with different domains or difficulty levels helps evaluate whether prompting strategies are reusable.

## My Reflection

This task helped me understand prompt engineering through practical and interactive challenges. Instead of only writing prompts theoretically, I was able to test how different prompting approaches perform across different situations.

The Prompt Performance Report also helped me understand the importance of evaluating prompts and refining them based on their results.

Replaying the puzzle with another domain or difficulty showed me that effective prompting requires adapting the instructions and context according to the specific task.
