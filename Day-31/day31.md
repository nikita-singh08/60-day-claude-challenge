# Day 31 – AI Supply Chain Control Tower

## Objective

Build and test an AI-powered Supply Chain Control Tower that helps monitor operational alerts, prioritize incidents, select corrective actions, and evaluate the impact of decisions on business KPIs.

## Task Performed

Today I used Claude AI to generate an interactive HTML application called **AI Supply Chain Control Tower**.

The workflow included:

1. Starting a new conversation in Claude.
2. Using the provided AI Supply Chain Control Tower prompt.
3. Generating the complete HTML application.
4. Saving the generated HTML file.
5. Opening the application in a web browser.
6. Reading the provided instructions.
7. Monitoring incoming operational alerts.
8. Prioritizing incidents based on urgency.
9. Choosing the best corrective action for each incident.
10. Observing KPI changes after each decision.
11. Managing multiple operational alerts simultaneously.
12. Completing the simulation.
13. Reviewing the final operational performance dashboard.
14. Replaying the simulation to improve the score.
15. Taking screenshots of the results.

## Key Learnings

- A supply chain control tower provides centralized visibility into operational problems.
- Incidents need to be prioritized according to urgency and business impact.
- Corrective actions can improve some KPIs while negatively affecting others.
- Monitoring multiple alerts simultaneously requires effective prioritization.
- Data-driven dashboards make operational decision-making easier.
- Replaying simulations helps understand how different decisions affect overall performance.

## My Reflection

This task helped me understand how AI-powered control towers can support real-time supply chain decision-making. The simulation demonstrated the importance of identifying critical incidents, selecting appropriate corrective actions, and continuously monitoring KPIs to improve operational performance.
