# Day 36 – Cognitive Pattern Explorer

## Objective

Build and test an interactive Cognitive Pattern Explorer that helps explore thinking patterns through everyday scenarios, interactive activities, reflection, and personalized analysis.

## Task Performed

Today I used Claude AI to generate an interactive HTML application called **Cognitive Pattern Explorer**.

The workflow included:

1. Opening Claude and setting the effort level to Low.
2. Using the provided Cognitive Pattern Explorer prompt.
3. Generating the complete HTML application.
4. Saving the generated HTML file.
5. Opening the application in a web browser.
6. Choosing Calm Mode or Stress Mode.
7. Completing Chapter 1 by responding to everyday scenarios.
8. Completing the drag-and-drop activities in Chapter 2.
9. Arranging the thinking sequence in Chapter 3.
10. Reviewing the personalized Reflection Journal.
11. Comparing thinking tendencies across all chapters.
12. Replaying the experience in the opposite mode.
13. Taking screenshots of the Reflection Journal and thinking profile.

## Key Learnings

- Different situations can influence the way we approach decisions and problems.
- Interactive scenarios can help identify patterns in how we respond to different situations.
- Organizing a thinking sequence can make the reasoning process easier to understand.
- Reflection can help identify recurring thinking tendencies.
- Comparing different modes provides a broader view of how responses can change across situations.
- Interactive tools can make self-reflection and cognitive learning more engaging.

## My Reflection

This task helped me explore how interactive scenarios can be used to understand different thinking patterns. Completing the chapters and reviewing the Reflection Journal provided a structured way to look back at my responses and compare tendencies across different activities.

Replaying the experience in the opposite mode also helped me observe how changing the context can lead to different responses and perspectives.
